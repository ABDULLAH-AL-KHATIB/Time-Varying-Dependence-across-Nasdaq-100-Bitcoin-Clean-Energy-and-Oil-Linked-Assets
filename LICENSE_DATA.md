# Input-data provenance and redistribution notice

The frozen historical price panel and its decimal log-return transformation are retained in the private author archive. The legacy file is named `verified_adjusted_close_prices.csv`, but the original manifest does not record the data provider, downloader, request arguments, timezone, or whether the chosen field was `Close`, `Adj Close`, or an auto-adjusted close. The file name alone does not establish the price-field convention. Earlier project notes describe Yahoo Finance as the historical source, but that attribution is not independently recorded in the run manifest.

Yahoo Finance's official help page says that information displayed on or provided by Yahoo Finance must not be redistributed: https://help.yahoo.com/kb/finance/article-exchanges-data-delays-sln2310.html. If the archived data are Yahoo-sourced, this restriction is directly relevant. More generally, because the original provider and applicable licence are not established from the archived execution record, this release conservatively excludes the raw price panel, return panel and date-level model outputs from the public GitHub/Zenodo staging directory. Do not publish them unless the provider is verified and redistribution is authorized, or the panel is replaced by a source with an appropriate open licence. Whether aggregate tables and figures can be redistributed must also be assessed under the actual source terms; this package does not make a legal determination.

The MIT licence applies only to original code authored for this project. It does not relicense market data, fund/index marks, third-party software or the manuscript. The public code expects `price_panel.csv` and `returns_decimal.csv` in `data/`; these must be lawfully obtained and documented by the user. The return file stores decimal log returns computed as `ln(P_t) - ln(P_{t-1})`. The analysis converts returns to percentage points before DSCC/QVAR estimation.
